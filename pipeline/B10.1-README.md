# SWTOR Survivors — B10.1 UI authenticity and menu refinement

B10.1 refines presentation and menu navigation only. Stop here for manual review.

## Launch

```powershell
& 'D:\SWTORClassic\torbonk\pipeline\Open-Survivors.ps1'
```

Choose **New Run → Sith Empire → Sith Inquisitor → Continue → Sorcerer → Continue → Korriban → Continue → Play**.
New Run opens allegiance with neither side highlighted and without the SWTOR logo. Faction selection advances after the existing brief reveal. Class, advanced class and destination choices update their previews and wait for **Continue** at the bottom-right of the screen, aligned with Back and Main Menu. Advanced class confirmation goes directly to Galaxy; character appearance is removed from this flow. Ready places **Play** in the same bottom-right navigation position. Back or Escape retains choices and follows the shortened flow. Appearance is handled separately through Main Menu → Collections.

The October 21 navigation follow-up reuses the existing SWTOR button artwork, standard-window frame and fonts. Its focused rendered checks are recorded in `manifests/b101-smoke.json`, with captures in `work/b101-{faction,base-class,advanced-class,galaxy,ready}.png` and the run log in `logs/ui-adjustments-runtime.log`. The notes below describe the earlier B10.1 milestone; the navigation above supersedes its automatic class/planet advancement and appearance step.

## Changes and audit findings

- Main menu now contains only New Run, Settings and Exit. Removed Character Selection, the custom slogan, session explanation and added Survivors label.
- Removed the step breadcrumb, configuration trail, debug JSON dialog/button, repeated navigation instructions, conversion/source codes, prototype descriptions and permanent preview-control captions. Preview controls remain available as a tooltip. Essential class descriptions, disabled appearance controls and preview-only restrictions remain visible.
- Frontend and HUD use recovered regular Eurostile with consistent text colors and shadows. The approved frontend button mapping and proportions are preserved: slice 9 at rest, 24 on hover, 18 on press, with the original padding. Only selection choices add a persistent selected rest state; ordinary menu buttons retain their existing styling. Removed custom gold button text and bold/gold headings. Preserved original gold pixels in the logo, allegiance heading, selected frame, cursor and reward effects. Warning and upgrade-rarity colors retain their meaning. Existing dedicated flytext font and behavior are unchanged.
- Panel titles sit inside the standard-window title strip; content starts below it. Nine-slice margins retain the window cap, shoulders and bevels. Faction panels retain the original character-creation panel with corrected interior spacing. Removed the redundant faction name heading above each faction button.
- Base and advanced class entries use a persistent original selected frame, including while focus is elsewhere. Unselected base-class icons are subdued; hover uses the approved original alternate button artwork. Existing ordinary menu button colors and focus styling are preserved. The session owns exactly one selected option. Selecting updates the artwork/details immediately, blocks additional menu input and then advances. Keyboard activation uses the same action as the mouse.
- Appearance retains the actual supported preset, 3D preview and eight disabled controls. The Sorcerer viewer now holds the existing illuminated red lightsaber, attached to the original right-hand weapon socket. This equipment belongs only to the preview. The preview has its own world, disables 2D rendering inside its offscreen viewport and fits the character and blade within the texture; shared logo/navigation controls remain alive across page changes and use an explicit draw order. Unimplemented classes show unavailable appearance values rather than falsely displaying the Sorcerer preset as their own.
- Galaxy retains the original Korriban illustration and single-destination restriction. Its selected frame persists, and selecting Korriban opens Ready directly. Ready retains host validation and visibly marks unsupported compositions as preview-only.
- Settings now uses the same original window/button composition, traps keyboard focus within its controls and retains the existing session-only interface-sound toggle.
- Wave, time and defeated counters now live in a compact 180×156 menu-style tracker on the upper left, using the same recovered `bwaui_standard_window_1` artwork as the selection menus. Uniform half-scale chrome plus nine-slice margins preserve the cap, shoulders and bevels. Labels and right-aligned values form three clean rows. On narrow windows the tracker moves below the existing boss dock to avoid overlap. Counter sources/behavior are unchanged. No PvP or portrait artwork is used.
- During boss encounters only the top boss name/health/phase frame remains. Removed the redundant Champion Encounter introduction panel; its existing start sound is retained. The post-defeat reward notice remains separate after the boss health frame closes.
- Focused gameplay pass: shared typography/button styling; native skill-tree artwork for upgrade-card focus; blue upgrade actions and encounter headings; pale boss phase/warning text instead of the remaining amber override; shallow original tooltip frame for boss health instead of crushing a tall window; corrected upgrade-window nine-slice cap. Unit frames, single 12-slot action bar, cooldown masks, XP presentation and cursor remain intact.

## Original resources and approximations

No archives, emulator files or original source assets were changed. No external fonts, icons or UI packs were introduced. Existing provenance is in `UI-PROVENANCE.md` and `../character-selection/ASSET-PROVENANCE.md`.

- Fonts: recovered `swtor_fonts.gfx` DefineFont3 Eurostile outlines (font 3). The recovered bold face (font 7) is used only for the restored level-up banner treatment; other headings retain regular Eurostile. Original hinting/kerning and native Scaleform font rendering are not reproduced.
- Chrome: `bwaui_standard_window` slices 1 (window), 9 (rest), 24 (hover/focus), 18 (selected/pressed); `bwaui_character_create_panels` slice 9; `bwaui_tooltip` slice 1; `bwaui_skilltree` slices 30/32. State assignments and nine-slice margins are Godot adaptations based on the recovered pixels, not newly proven native timeline bindings.
- Original logo/allegiance title and faction emblems remain artwork. Other headings use recovered Eurostile. Pale text and blue heading colors are consistent SWTOR-derived styling, not claimed pixel-exact native text-field values.
- Preview equipment reuses the recovered B6 saber hilt and socket correction through `EquipmentAttachment`. Its existing red blade/halo is a Godot reconstruction using the recovered tip texture, as documented in B6; no new weapon assets or effects were invented. The viewer retargets the already converted original BMN `cb_knight_saber_idle_1.jba` from the B6 looter animation library onto the preview skeleton; animation tracks and loop settings are duplicated locally. The Sorcerer now holds the hilt in a saber-ready stance rather than the unarmed fists-up idle. Preview framing includes the full raised blade. The imported source models and gameplay animations remain unchanged. No lightning-channel effect was added.
- Complete native class-list widgets were not reconstructed. The existing SWTOR-derived button component supplies consistent focus, hover and selection feedback. No new borders are drawn around frames.
- Layout, transitions, descriptions and simplified Korriban destination composition are authored. No native Scaleform logic is executed.
- Only Empire / Sith Inquisitor / Sorcerer / Korriban is playable. All eight base classes and sixteen classic advanced classes remain previewable. Only Sorcerer has a 3D preview. Appearance editing and broader settings remain unavailable.
